# Mation Blur

動画にモーションブラーを追加するWindowsアプリです。

## EXEの作成

1. Python 3.10以降をインストールし、Pythonランチャー (`py`) を使用できるようにします。
2. `build.bat` をダブルクリックします。
3. このフォルダーに作成された `Mation Blur.exe` を起動します。

初回ビルド時はPyInstaller、Pillow、FFmpegのダウンロードにインターネット接続が必要です。`mation.png` はアプリとEXEのアイコンに使用されます。作成したEXEにはFFmpegが同梱され、別途FFmpegをインストールする必要はありません。

## 使い方

1. `Mation Blur.exe` を開きます。
2. 動画を追加します。入力できる形式・コーデックは同梱FFmpegが対応するものです。
3. 保存先、ブラーの強さ、書き出し画質を選び、処理を開始します。
4. `_motion_blur` を付けたMP4ファイルが保存されます。

画質スライダーを「高画質」にすると、圧縮による劣化を抑えられますが、ファイルサイズは大きくなります。初期設定は高画質寄りです。「ブラーの滑らかさ」では中間フレームの補間倍率を2～8倍で指定できます。倍率を上げると細かく合成できますが、処理時間も長くなります。出力フレームレートは元動画に合わせ、音声がある場合は保持します。フレーム数を増やすとブラーが強くなります。
