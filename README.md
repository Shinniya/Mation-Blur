# Mation Blur

動画に滑らかなモーションブラーを加える Windows アプリです。複数の動画をまとめて処理し、ブラーの強さ、滑らかさ、書き出し画質を調整できます。

## 動作環境

- Windows 10 / 11（64 ビット）
- アプリのインストールや、FFmpeg の別途インストールは不要です。

## 使い方

1. `Mation-Blur-x.exe` を起動します。
2. **「動画を追加...」** を押し、処理する動画を1つ以上選びます。
3. 保存先フォルダーを選びます。初期設定はユーザーの `Videos` フォルダーです。
4. 必要に応じてブラーの強さ、滑らかさ、書き出し画質を調整します。
5. **「処理開始」** を押します。処理中は進行状況が表示され、必要に応じてキャンセルできます。

処理結果は保存先に MP4 形式で作成されます。ファイル名には `_motion_blur` が追加されます。出力先に同名のファイルがある場合は、元ファイルを上書きせず、末尾に連番を付けて保存します。

## 設定

| 設定 | 範囲 | 初期値 | 説明 |
| --- | ---: | ---: | --- |
| ブラーの強さ | 2～15 フレーム | 5 フレーム | 合成する時間範囲を調整します。値を大きくするとブラーが強くなります。 |
| ブラーの滑らかさ | 2～8 倍 | 4 倍 | 中間フレームの補間倍率を調整します。値を大きくすると細かく滑らかになりますが、処理に時間がかかります。 |
| 書き出し画質 | CRF 10～30 | CRF 14 | 圧縮の度合いを調整します。「高画質」側ほど圧縮が少なく、ファイルサイズが大きくなります。 |

補間倍率を上げても、書き出し動画のフレームレートは基本的に元動画に合わせます。補間したフレームを使ってブラーを滑らかに合成する設定であり、出力を高フレームレート化する設定ではありません。

## 対応動画

入力形式は同梱 FFmpeg が読み込める形式・コーデックに依存します。一般的な MP4、MOV、MKV、AVI などを読み込めますが、すべての形式や特殊なコーデックを保証するものではありません。

書き出しは MP4（H.264 映像、AAC 音声）です。入力に音声がある場合は音声も出力します。

## ヒントと制限

- 滑らかさやブラーの強さを上げると、処理時間が長くなる場合があります。
- 動きが非常に速い場面、遮蔽物で隠れる場面、シーン切り替えでは、中間フレームに残像や補間の乱れが生じることがあります。
- 出力動画の画質は、設定だけでなく元動画の解像度・画質にも左右されます。
- 処理中にキャンセルした場合、処理途中のファイルは出力されません。すでに完了したファイルはそのまま保存されます。

## 配布について

Mation Blur は非オープンソースのソフトウェアです。この README はアプリの利用方法を説明するものです。
